## ✨ About

SHRINKO is a web-based file compression platform that helps users reduce file sizes through a simple and accessible interface.

It connects a React-based frontend with a Python FastAPI backend to handle file uploads, processing and compressed output.

## 🚀 Features

- 📁 File upload and compression
- ⚡ Backend-powered file processing
- 📊 Compression results
- 🎨 Modern and responsive interface
- 🔄 Frontend and backend API integration

## 🛠️ Tech Stack

| Frontend | Purpose |
|---|---|
| React 19 | User interface and components |
| TypeScript | Type-safe development |
| Vite | Development and build tooling |
| Tailwind CSS 4 | Responsive styling |
| Framer Motion | UI animations |

| Backend | Purpose |
|---|---|
| Python | Backend development |
| FastAPI | REST API and file processing |
| Uvicorn | Application server |
| PyMuPDF | PDF processing |
| Pillow, OpenCV, NumPy | Image and numerical processing |

**Deployment:** Render  
**Version Control:** Git & GitHub

## 🔄 How It Works

1. **Upload** – Select a supported file.
2. **Process** – The frontend sends it to the backend API.
3. **Compress** – The backend processes the file.
4. **Download** – Access the processed output.
